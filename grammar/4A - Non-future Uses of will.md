## Core idea

We often think of `will` as a future form, but it also has several **non-future uses**.

We can use `will` to talk about:

- guesses about the present
- present habits
- refusals
- insistence / annoying repeated behaviour

## Main uses

### 1. Inferences

We use `will` to make guesses about present states.

| Case | Form | Example                                                                  |
|------|------|--------------------------------------------------------------------------|
| guess about a present state | will + base verb | Why not ask David? He **’ll know** the answer, I’m sure.                 |
| guess about what is happening now | will be + V-ing | You **’ll be wondering** why I’m wearing a suit, I imagine.              |
| guess about a past event | will have + V3 | Anna’s been in a meeting all day, so she **won’t have read** your email. |

### 2. Habits

We use `will` to talk about long-term present habits.

| Case | Form | Example |
|------|------|---------|
| regular / typical present behaviour | will + base verb | My dad**’ll get up** early every Saturday to go fishing. |

For past habits, we usually use `would`.

| Case | Form | Example |
|------|------|---------|
| regular / typical past behaviour | would + base verb | When I was younger, we **would go** there every summer. |

Use `used to`, not `would`, for **past states**.

| Case | Form | Example |
|------|------|---------|
| past state | used to + base verb | When I was a child, my mum **used to own** a shop. |

### 3. Refusals and insistence

We use `won’t` to say that a person or thing refuses to do something.

| Case | Form | Example |
|------|------|---------|
| refusal by a person or thing | won’t + base verb | There’s something wrong with this door. It **won’t open**. |
| past refusal | wouldn’t + base verb | When I was a child, I **wouldn’t eat** vegetables. |

We can stress `will` to complain about repeated, annoying, or insistent behaviour.

| Case | Form | Example |
|------|------|---------|
| insistence / annoying repeated behaviour | will + base verb | I’m not surprised you feel tired, but you **will stay up** late watching videos, won’t you? |

## Which form to use

| Meaning | Form | Example                                  |
|---------|------|------------------------------------------|
| I guess this is true now | will + base verb | He **’ll know** the answer.              |
| I guess this is happening now | will be + V-ing | You **’ll be wondering** why I’m here.   |
| I guess this happened before now | will have + V3 | She **won’t have seen** the message yet. |
| this is a present habit | will + base verb | He**’ll sit** there for hours.           |
| this was a past habit | would + base verb | He **would sit** there for hours.        |
| this was a past state | used to + base verb | He **used to live** here.                |
| refusal now | won’t + base verb | My car **won’t start**.                  |
| refusal in the past | wouldn’t + base verb | The baby **wouldn’t sleep**.             |
| annoying insistence | stressed `will` + base verb | She **will keep** interrupting me.       |

## Will vs would vs used to

| Use | Will | Would | Used to |
|-----|------|-------|---------|
| present inference | yes | no | no |
| present habit | yes | no | no |
| past habit | no | yes | yes |
| past state | no | no | yes |
| refusal | won’t | wouldn’t | no |

## Common mistakes

| Wrong | Correct | Why |
|------|---------|-----|
| When I was a child, my mum would own a shop. | When I was a child, my mum used to own a shop. | `Would` is not normally used for past states. |
| He will be knowing the answer. | He’ll know the answer. | For present-state inferences, use `will` with state verbs, not continuous. |
| My car wouldn’t start now. | My car won’t start now. | Use `won’t` for present refusal / failure. |
| He used to go there every Saturday when he was young. | He would go there every Saturday when he was young. | Both are possible for repeated past actions, but `would` is often used for habitual past actions in this meaning. |

## Quick choice guide

| If you want to say... | Use... | Form |
|-----------------------|---------|------|
| догадка о состоянии сейчас | inference | will + base verb |
| догадка о процессе сейчас | inference | will be + V-ing |
| догадка о прошлом событии | inference | will have + V3 |
| привычка в настоящем | habit | will + base verb |
| привычка в прошлом | past habit | would + base verb |
| состояние в прошлом | past state | used to + base verb |
| отказ сейчас | refusal | won’t + base verb |
| отказ в прошлом | past refusal | wouldn’t + base verb |
| раздражающая настойчивость | insistence | stressed will + base verb |
